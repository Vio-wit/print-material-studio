# 物料工坊

一个从照片与可打印平面物料开始的本地设计工作台。它仍在开发中，不是已经完成的线上作品发布平台。

## 当前能做什么

- 导入常见图片，或复制图片后在编辑页面按 Ctrl + V 粘贴。
- 调整曝光、对比度、高光、阴影、冷暖、色调、鲜艳度等；使用几种轻量色调预设。
- 在浏览器本机识别人像，并单独调整人物曝光和对比度；选区边缘可能有误差。
- 在浏览器本机读取图片尺寸和常见 EXIF 相机信息；编辑器不会为了读取这些信息而上传原图。
- 选择常用相纸、卡片和 A5 画布尺寸；图片保持比例、居中放置，不会被强行裁切。
- 一键套用横向票根模板，填写活动信息和副券编号；透明 PNG 可用于沿轮廓裁切，打印 PDF 仍是矩形页面。
- 导出 300 DPI PNG 或单页 RGB PDF。
- 把作品和素材保存在当前浏览器的本地数据库中；清除浏览器数据可能会删除它们，请把重要作品另行导出备份。
- 查看想做清单、调整想法状态或添加新想法。清单也保存在当前浏览器。

## 运行环境

- Node.js 20.19 或更新版本
- Python 3.11 或更新版本（仅在需要启动可选 API 服务时需要）
- Windows 可用 Git Bash、PowerShell 或 Windows Terminal

首次启动前端，在项目目录执行：

    npm install
    npm run dev

浏览器打开 http://localhost:3000。照片导入、调整、EXIF 读取和导出均可在浏览器中使用；照片保存在当前浏览器，不会自动上传。

如需单独运行可选的 FastAPI 本地 API：先创建 Python 虚拟环境并安装 `requirements.txt`，再执行 `npm run dev:api`。前端照片编辑和 EXIF 读取不依赖此服务。

## 目前的边界

- 保存位置是当前浏览器，不是云盘，也不会自动同步到其他电脑或浏览器。
- 当前 PDF 是把高分辨率 RGB 图片放入单页 PDF；CMYK、PDF/X、出血线、色彩校样和印厂规范尚未开发。
- 人脸精修、皮肤处理等美颜功能尚未开发；当前主体选择只支持人物区域的曝光和对比度调整。
- 书籍/杂志/报纸的多页编排、在线作品展示、AI 抠图、相机 RAW 解码、绘画工具和 3D 预览尚未开发；3D 已明确暂缓。
- 设计模板目前是少量基础纸张尺寸，后续可按真实打印和装订需求扩展。

## 技术结构

- Nuxt 4、Vue 3 与 TypeScript：网页界面和照片编辑。
- FastAPI 与 Pillow：可选的本机 API 服务；当前编辑器的照片信息在浏览器本机读取。
- exifr：在浏览器本机解析图片 EXIF 元数据。
- IndexedDB：在当前浏览器中本地保存作品、素材和想法。
- pdf-lib：在浏览器中生成单页 PDF。
